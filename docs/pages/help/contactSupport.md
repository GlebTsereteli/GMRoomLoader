# Contact & Support

## Getting Help

Need help with GMRoomLoader?

Drop a message in the `#gleb___gmroomloader` channel on the [GameMaker Kitchen](https://discord.gg/gamemakerkitchen) Discord server, start a topic on the [itch.io board](https://glebtsereteli.itch.io/gmroomloader/community), or open a :New Issue: with the `help` label.

### Before Asking

Please read the relevant documentation pages first, and check the [FAQ](/pages/help/faq) and [Troubleshooting](/pages/home/troubleshooting) pages to see if your question is already answered there.

### Keep It Relevant

My support is limited to questions directly related to GMRoomLoader. When it comes to procedural generation or other level layout setups, I'm happy to discuss general ideas, but not implementation specifics.

For help with those topics, feel free to use the `#help` channels on the [GameMaker](https://discord.com/invite/gamemaker) Discord server, the `#questions` channel on the [GameMaker Kitchen](https://discord.gg/gamemakerkitchen) Discord server, the [r/GameMaker](https://www.reddit.com/r/gamemaker/) subreddit, or the GameMaker [Community Forums](https://forum.gamemaker.io/).

### Personal Help

If you need a tailored solution for your project, I'm happy to take on both short commissions and longer-term work. Feel free to DM me on Discord `@GlebTsereteli`, [Twitter](https://x.com/glebtsereteli) or [Bluesky](https://bsky.app/profile/glebtsereteli.bsky.social) to discuss the details.

## Bugs & Features

* Found a bug? Please open a :New Issue: with the `bug` label.
* Got a feature request for something you'd like to see added? Please open a :New Issue: with the `feature` label.
